Project Description:

Ok, I thought about doing a German tracker, where I can have flashcards and add words.
I've been learning German, and one of the issues I face is remembering all the different cases and forms that words can have.
On top of this, most apps require you to pay for some of their features.

So, the idea is that when you enter a word, the application will give you the meaning and information about the word, such as its article,
plural form, cases, and how it can be used in a sentence. The user can then save the word and use it later to create flashcards and practice.

I also want the application to help users understand why a word changes depending on the situation instead of just memorizing it.
For example, if the user enters a German noun, the application could show how the article changes between nominative, accusative, dative, and genitive.
The goal is to create a free and simple tool that helps German learners organize vocabulary while also understanding German grammar and practicing the areas they have the most difficulty with.
