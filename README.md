##Problem Statement

Learning German can be challenging because of the different grammatical cases, articles, and word forms. Many language learning applications offer limited grammar practice or require users to pay for advanced features. I want to develop a German Learning Tracker that allows users to save vocabulary, practice using flashcards, and review German articles and cases. The goal is to create an application that makes learning German more organized, accessible, and easier to practice consistently.
